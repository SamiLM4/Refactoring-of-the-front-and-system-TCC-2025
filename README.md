🧠 Pré-Diagnóstico de Esclerose Múltipla com IA Generativa








Sistema inteligente de apoio ao pré-diagnóstico da Esclerose Múltipla, utilizando Processamento de Imagens Médicas e Inteligência Artificial Generativa.

📚 Trabalho de Conclusão de Curso (TCC)
🎓 Ensino Médio Técnico em Informática – UNIVAP
📅 Ano: 2025

📌 Visão Geral

A Esclerose Múltipla (EM) é uma doença neurológica complexa, cujo diagnóstico precoce pode ser um grande desafio. Este projeto propõe o desenvolvimento de uma plataforma web capaz de organizar dados clínicos, processar informações médicas e gerar um pré-diagnóstico automatizado, atuando como uma ferramenta de apoio à análise clínica.

⚠️ Aviso importante:
Este sistema não substitui o diagnóstico médico profissional. Os resultados gerados possuem caráter auxiliar, educacional e experimental.

🚀 Funcionalidades Principais

🔐 Autenticação de usuários

👤 Cadastro e gerenciamento de pacientes

📋 Listagem de pacientes sem diagnóstico definido

🧠 Ficha de anamnese específica para Esclerose Múltipla

📄 Geração e download de ficha médica em PDF

✏️ Atualização de dados clínicos

🤖 Pré-diagnóstico automatizado com IA Generativa

📊 Interface limpa, intuitiva e organizada
